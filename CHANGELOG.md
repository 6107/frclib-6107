## v2027.0.0.2

Initial release of the 2027 version of lib_6107. This is a major release with breaking changes
from the 2026 version due to the change to SystemCore and heavy WPILib and robotpy refactoring.
The 2027 version of lib_6107 is not compatible with the 2026 version.

The following are the highlights of this release:

 - Significant refactoring of the lib_6107 codebase to improve maintainability and readability.
 - Simulation support for the lib_6107 library, allowing for testing and development without
   physical hardware. Currently, 2027-tuner-x telop simulation is working.
